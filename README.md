# whisper-android

Standalone Android library wrapping [whisper.cpp](https://github.com/ggml-org/whisper.cpp)
(JNI + CMake) for on-device speech-to-text. Extracted from Enclave's `:whisper-android`
module (Linear ENC-46) so it can be shared by Enclave and Bloviate.

See the module README sections below once the library lands; this file is the repo bootstrap.
